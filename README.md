# موقع مكتبة إعدادية دجلة الخير للبنين — النشر

قاعدة البيانات والتخزين والصلاحيات وحساب المالك جاهزة في مشروع Supabase باسم Dajla، وconfig.js مضبوط عليه.

## النشر
1. ارفع index.html و config.js إلى مستودع في github.com (Add file ← Upload files).
2. vercel.com ← Add New ← Project ← اختر المستودع ← Deploy.
3. افتح الرابط ← «دخول المالك» أسفل الرئيسية ← اسم المستخدم: ahmed_ali

## أمان
- غيّر كلمة المرور بعد أول دخول (Supabase ← Authentication ← Users).
- عطّل التسجيل الذاتي: Authentication ← Sign In / Providers ← Allow new users to sign up = Off.
- لا تكتب كلمة المرور في أي ملف، ولا تضع مفتاح service_role في الموقع.

## ملاحظات
- القراءة العامة للمحتوى فقط؛ الكتابة والرفع للمالك وحده؛ سجل الإعارات للمالك وحده.
- صور حتى 8 م.ب وPDF حتى 50 م.ب. رابط الملف عام لمن يعرفه فلا ترفع ملفات سرّية.
- المشروع المجاني يتوقف بعد أسبوع دون نشاط (Restore من لوحة Supabase).
